### 📘 Spec — RFC-0005: Generator Decomposition

**Versão:** 1.0
**Status:** Aprovado (ADR-0010)
**Baseado em:** RFC-0005, ADR-0010

----------

### 1. Objetivo

Decompor o `FlowCodeGenerator` monolítico em writers especializados, eliminando duplicação entre `GenerateMapMethod` e `GenerateNestedMethod` e melhorando testabilidade.

----------

### 2. Interface

```csharp
// Pipeline/Generator/ICodeWriter.cs
namespace FlowMapper.SourceGenerator.Pipeline.Generator;

public interface ICodeWriter
{
    void Write(CodeWriterContext context, StringBuilder sb);
}
```

### 3. Context

```csharp
public class CodeWriterContext
{
    public Flow Flow { get; init; } = null!;
    public string MapperName { get; init; } = string.Empty;
    public bool IsNested { get; init; }       // true quando é método nested
    public string? MethodName { get; init; }  // nome do método (Map ou MapXxx)
}
```

### 4. Writers

### 4.1 `UsingWriter`

**Responsabilidade:** Escrever diretivas `using` e cabeçalho `// <auto-generated />`.

```csharp
public class UsingWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        sb.AppendLine("// <auto-generated />");
        sb.AppendLine("#pragma warning disable CS0105, CS8618, CS0649");
        sb.AppendLine("using FlowMapper.Abstractions;");
        sb.AppendLine("using FlowMapper.Core;");
        sb.AppendLine();
    }
}
```

> Executado **uma vez** no início, não por flow.

### 4.2 `NamespaceWriter`

**Responsabilidade:** Escrever declaração de namespace.

```csharp
public class NamespaceWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        if (context.Flow.ProfileName != "Default")
            sb.AppendLine($"namespace FlowMapper.SourceGenerator.Profiles.{context.Flow.ProfileName};");
        else
            sb.AppendLine("namespace FlowMapper.SourceGenerator;");
        sb.AppendLine();
    }
}
```

> Executado **uma vez** com o primeiro flow (todos compartilham o mesmo namespace).

### 4.3 `ClassWriter`

**Responsabilidade:** Escrever declaração da classe, atributos e abertura/fechamento.

```csharp
public class ClassWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        if (context.Flow.ProfileName != "Default")
            sb.AppendLine($"[FlowProfile(\"{context.Flow.ProfileName}\")]");

        sb.AppendLine($"public partial class {context.MapperName} " +
                      $": IMapper<{context.Flow.SourceType}, {context.Flow.DestinationType}>");
        sb.AppendLine("{");
        // Fechamento é feito pelo orquestrador
    }
}
```

### 4.4 `ConstructorWriter`

**Responsabilidade:** Escrever a construção do objeto destino.

| Entrada | Saída |
|---------|-------|
| `ConstructUsingMethod` não nulo | `var target = {method}(source);` |
| `Strategy.Constructor` ativo | `var target = new TDest(p1, p2, ...);` |
| Padrão (mutável) | `var target = new TDest();` |

```csharp
public class ConstructorWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        var flow = context.Flow;
        var constructorProps = flow.Properties
            .Where(p => p.Strategy == MappingStrategy.Constructor)
            .OrderBy(p => p.ConstructorParameterIndex)
            .ToList();

        if (flow.ConstructUsingMethod != null)
        {
            sb.AppendLine($"        var target = {flow.ConstructUsingMethod}(source);");
        }
        else if (constructorProps.Count > 0)
        {
            sb.Append("        var target = new ");
            sb.Append(flow.DestinationType);
            sb.Append('(');
            for (int i = 0; i < constructorProps.Count; i++)
            {
                if (i > 0) sb.Append(", ");
                sb.Append($"source.{constructorProps[i].SourceProperty}");
            }
            sb.AppendLine(");");
        }
        else
        {
            sb.AppendLine($"        var target = new {flow.DestinationType}();");
        }
    }
}
```

### 4.5 `PropertyWriter`

**Responsabilidade:** Escrever atribuições de propriedades (Direct, Flatten, MapFromExpression).

```csharp
public class PropertyWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        var flow = context.Flow;
        var assignProps = flow.Properties
            .Where(p => p.Strategy is MappingStrategy.Direct or MappingStrategy.Flatten)
            .ToList();

        foreach (var prop in assignProps)
        {
            if (prop.MapFromExpression != null)
            {
                var expr = NormalizeExpression(prop.MapFromExpression);
                sb.AppendLine($"        target.{prop.DestinationProperty} = {expr};");
            }
            else
            {
                var sourceAccess = prop.Strategy == MappingStrategy.Flatten
                    ? $"source.{prop.SourcePath}"
                    : $"source.{prop.SourceProperty}";
                sb.AppendLine($"        target.{prop.DestinationProperty} = {sourceAccess};");
            }
        }
    }

    private static string NormalizeExpression(string expr)
        => expr.Replace("$", "").Replace("\"", "\"");
}
```

### 4.6 `NestedWriter`

**Responsabilidade:** Escrever chamadas a métodos nested e gerar os métodos nested.

```csharp
public class NestedWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        var flow = context.Flow;

        // Chamadas no método principal
        foreach (var nested in flow.NestedFlows)
        {
            var methodName = GetNestedMethodName(nested.ParentProperty);
            sb.AppendLine($"        target.{nested.ChildFlow.DestinationType} = " +
                         $"{methodName}(source.{nested.ParentProperty});");
        }

        // Geração dos métodos nested
        foreach (var nested in flow.NestedFlows)
        {
            sb.AppendLine();
            WriteNestedMethod(sb, nested);
        }
    }

    private static void WriteNestedMethod(StringBuilder sb, NestedFlow nested)
    {
        var childFlow = nested.ChildFlow;
        var methodName = GetNestedMethodName(nested.ParentProperty);

        sb.AppendLine($"    private {childFlow.DestinationType} {methodName}({childFlow.SourceType} source)");
        sb.AppendLine("    {");

        // Reusa ConstructorWriter + PropertyWriter para o nested flow
        var nestedContext = new CodeWriterContext
        {
            Flow = childFlow,
            IsNested = true,
            MethodName = methodName
        };

        new ConstructorWriter().Write(nestedContext, sb);
        new PropertyWriter().Write(nestedContext, sb);

        // Nested recursivo
        foreach (var childNested in childFlow.NestedFlows)
        {
            var childMethodName = GetNestedMethodName(childNested.ParentProperty);
            sb.AppendLine($"        target.{childNested.ChildFlow.DestinationType} = " +
                         $"{childMethodName}(source.{childNested.ParentProperty});");
        }

        sb.AppendLine("        return target;");
        sb.AppendLine("    }");
    }

    private static string GetNestedMethodName(string propertyName)
        => $"Map{propertyName}";
}
```

### 4.7 `AfterMapWriter`

**Responsabilidade:** Escrever chamada `AfterMap` quando configurada.

```csharp
public class AfterMapWriter : ICodeWriter
{
    public void Write(CodeWriterContext context, StringBuilder sb)
    {
        if (context.Flow.AfterMapMethod != null)
        {
            sb.AppendLine($"        {context.Flow.AfterMapMethod}(source, target);");
        }
    }
}
```

### 5. Orquestrador Refatorado

```csharp
public static class FlowCodeGenerator
{
    public static string Generate(FlowModel model)
    {
        var sb = new StringBuilder();

        var usingWriter = new UsingWriter();
        var namespaceWriter = new NamespaceWriter();
        var classWriter = new ClassWriter();
        var constructorWriter = new ConstructorWriter();
        var propertyWriter = new PropertyWriter();
        var nestedWriter = new NestedWriter();
        var afterMapWriter = new AfterMapWriter();

        bool headerWritten = false;

        foreach (var flow in model.Flows)
        {
            var context = new CodeWriterContext
            {
                Flow = flow,
                MapperName = model.MapperName,
                IsNested = false,
                MethodName = "Map"
            };

            if (!headerWritten)
            {
                usingWriter.Write(context, sb);
                namespaceWriter.Write(context, sb);
                headerWritten = true;
            }

            classWriter.Write(context, sb);
            WriteMapMethod(sb, context, constructorWriter, propertyWriter, nestedWriter, afterMapWriter);
            sb.AppendLine("}");
        }

        return sb.ToString();
    }

    private static void WriteMapMethod(
        StringBuilder sb, CodeWriterContext context,
        ConstructorWriter constructorWriter, PropertyWriter propertyWriter,
        NestedWriter nestedWriter, AfterMapWriter afterMapWriter)
    {
        sb.AppendLine($"    public {context.Flow.DestinationType} Map({context.Flow.SourceType} source)");
        sb.AppendLine("    {");

        constructorWriter.Write(context, sb);
        propertyWriter.Write(context, sb);
        nestedWriter.Write(context, sb);
        afterMapWriter.Write(context, sb);

        sb.AppendLine("        return target;");
        sb.AppendLine("    }");
    }
}
```

### 6. O que muda

| Arquivo | Ação |
|---------|------|
| `FlowCodeGenerator.cs` | Refatorar: orquestrador + delegação para writers |
| `ICodeWriter.cs` | **Criar**: interface |
| `CodeWriterContext.cs` | **Criar**: contexto compartilhado |
| `UsingWriter.cs` | **Criar**: usings + header |
| `NamespaceWriter.cs` | **Criar**: namespace |
| `ClassWriter.cs` | **Criar**: class declaration |
| `ConstructorWriter.cs` | **Criar**: constructor calls |
| `PropertyWriter.cs` | **Criar**: property assignments |
| `NestedWriter.cs` | **Criar**: nested methods |
| `AfterMapWriter.cs` | **Criar**: after-map callback |

Output gerado deve ser **100% idêntico** ao atual.
