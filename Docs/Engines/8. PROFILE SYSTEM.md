### 🧩 FLOWMAPPER v1 — PROFILE SYSTEM (CONVENTIONS POR CONTEXTO)

----------

### 🧠 1. VISÃO DO SISTEMA

O Profile System permite que o FlowMapper tenha **regras diferentes de mapeamento dependendo do contexto**.

Exemplos reais:

-   🟢 API → DTO (simples, flat, direto)
-   🟡 Domain → DTO (flatten + constructor)
-   🔴 Integration → External API (renaming + strict mode)

----------

### 🎯 2. OBJETIVO

O sistema deve permitir:

-   📦 múltiplos profiles por projeto
-   ⚙️ regras de convenção diferentes por profile
-   🧠 isolamento de flows por contexto
-   🔁 reutilização de engine (sem duplicar código)
-   ⚡ geração compile-time ainda mantida

----------

### 🚫 3. FORA DE ESCOPO (v1)

Não entra aqui:

-   profile dinâmico em runtime
-   troca de profile por request HTTP
-   multi-tenant mapping engine
-   carregamento remoto de profiles

----------

### 🧱 4. NOVO CONCEITO — PROFILE

Um Profile define:

> um conjunto de regras de mapeamento aplicadas a um grupo de mappers

----------

### 📄 Exemplo:

```csharp
[FlowProfile("Api")]
public class ApiProfile { }
```

----------

### 🧠 5. COMO O PROFILE AFETA O FLOW

Agora cada Flow passa a ter:

```
Flow
├── SourceType
├── DestinationType

├── Policy

```

### ⚙️ 10. PROFILE CONVENTION ENGINE

Cada profile pode alterar comportamento:

----------

### 🟢 API PROFILE (simples)

```
- direct mapping only
- no flatten
- constructor optional
```

----------

### 🟡 DOMAIN PROFILE

```
- constructor preferred
- flatten enabled
- strict validation
```

----------

### 🔴 INTEGRATION PROFILE

```
- rename allowed (future)
- strict mapping required
- all properties must be mapped
```

### 🔁 12. PROFILE RESOLVER

📄 ProfileResolver.cs

```csharp
public static class ProfileResolver
{
    public static string Resolve(INamedTypeSymbol mapper, Compilation compilation)
    {
        // 1. Mapper attribute
        var attr = mapper.GetAttributes()
            .FirstOrDefault(a => a.AttributeClass?.Name == "MapAttribute");

        var profileArg = attr?.ConstructorArguments
            .FirstOrDefault();

        if (profileArg.Value != null)
            return profileArg.Value.ToString();

        // 2. Assembly attribute
        var asmAttr = compilation.Assembly.GetAttributes()
            .FirstOrDefault(a => a.AttributeClass?.Name == "FlowProfileAttribute");

        if (asmAttr != null)
            return asmAttr.ConstructorArguments[0].Value.ToString();

        // 3. default
        return "Default";
    }
}
```
