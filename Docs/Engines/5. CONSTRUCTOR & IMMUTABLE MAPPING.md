### 🧱 FLOWMAPPER v1 — CONSTRUCTOR & IMMUTABLE MAPPING

----------

### 🧠 1. VISÃO DO FEATURE

O FlowMapper agora deve suportar:

> objetos que NÃO podem ser preenchidos via set, apenas via construtor

Inclui:

-   records
-   classes com construtor obrigatório
-   init-only properties
-   tipos imutáveis (DDD style)

----------

### 🎯 2. OBJETIVO

Permitir gerar código para:

-   🧾 Record types
-   🔒 Immutable classes
-   🧠 Constructor binding automático
-   ⚡ Mix (constructor + init setters quando possível)

----------

### 🚫 3. FORA DE ESCOPO (v1)

Não entra ainda:

-   múltiplos construtores complexos (escolha heurística avançada)
-   DI no construtor do DTO
-   factories customizadas
-   builders fluent
-   parâmetros opcionais inteligentes

----------

### 🧱 4. NOVO MODELO DE DECISÃO

Agora cada FlowProperty pode ser resolvido de 2 formas:

----------

### 🔵 Strategy 1 — Property Assignment

```csharp
new UserDto
{
    Name = source.Name
}
```

----------

### 🟣 Strategy 2 — Constructor Binding

```csharp
new UserDto(source.Name, source.Id)
```

----------

### 🧠 5. DETECÇÃO DE IMUTABILIDADE

### Regra v1:

Um tipo é considerado IMUTÁVEL quando:

-   ❌ não tem setter público
-   ✔ possui construtor com parâmetros correspondentes
-   ✔ ou é record

----------

PropertyFlow

### 🧠 7. FLOW BUILDER (ATUALIZADO)

Agora ele faz 2 fases:

----------

### 🔵 FASE 1 — Detectar propriedades setáveis

```csharp
if (destProp.SetMethod != null)
{
    use assignment strategy
}
```

----------

### 🟣 FASE 2 — fallback para construtor

```scharp

```

### 🧾 8. EXEMPLO 1 — RECORD (CASO IDEAL)

## Input

```csharp
public record UserDto(int Id, string Name);
```

----------

### Output gerado

```csharp
public partial class UserMapper
{
    public UserDto Map(User source)
    {
        return new UserDto(
            source.Id,
            source.Name
        );
    }
}
```

----------

### 🧾 9. EXEMPLO 2 — MIX (SET + CONSTRUCTOR)

```csharp
public class UserDto
{
    public int Id { get; init; }
    public string Name { get; init; }

    public UserDto(int id)
    {
        Id = id;
    }
}
```

----------

### Resultado

```csharp
return new UserDto(source.Id)
{
    Name = source.Name
};
```
