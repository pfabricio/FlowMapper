### 🧩 FLOWMAPPER v1 — FLUENT CONFIGURATION API (FlowMapperOptions)

----------

### 🧠 1. VISÃO DO SISTEMA

O objetivo agora é criar uma API fluente para configurar o comportamento global do FlowMapper.

> Em vez de depender só de atributos, o usuário pode controlar o framework por código.

Isso é o que separa:

-   ❌ biblioteca rígida
-   ✔ framework configurável

----------

### 🎯 2. OBJETIVO

Permitir configurar:

-   ⚙️ profiles globais
-   🌳 flatten habilitado/desabilitado
-   🧠 strategy padrão (constructor vs object initializer)
-   ⚠️ modo de validação (strict/warn/none)
-   ⚡ cache behavior
-   🔁 fallback rules

----------

Não entra aqui:

-   configuração por request HTTP
-   runtime hot reload de config
-   config distribuída (DB/Redis)

### ⚙️ 5. FLUENT API DESIGN

Agora criamos a API principal:

----------

📄 FlowMapperConfigurationBuilder.cs

```csharp
using FlowMapper.Abstractions;

namespace FlowMapper;

public class FlowMapperConfigurationBuilder
{
    private readonly FlowMapperOptions _options = new();

    public FlowMapperConfigurationBuilder UseDefaultProfile(string profile)
    {
        _options.DefaultProfile = profile;
        return this;
    }

    public FlowMapperConfigurationBuilder EnableFlatten(bool enabled = true)
    {
        _options.EnableFlatten = enabled;
        return this;
    }

    public FlowMapperConfigurationBuilder PreferConstructor(bool enabled = true)
    {
        _options.PreferConstructorMapping = enabled;
        return this;
    }

    public FlowMapperConfigurationBuilder StrictMode()
    {
        _options.Strictness = StrictnessLevel.Error;
        return this;
    }

    public FlowMapperConfigurationBuilder WarnMode()
    {
        _options.Strictness = StrictnessLevel.Warning;
        return this;
    }

    public FlowMapperConfigurationBuilder DisableCache()
    {
        _options.EnableCache = false;
        return this;
    }

    public FlowMapperOptions Build()
        => _options;
}
```

### 🧠 6. EXTENSÃO DE DI (ENTRY REAL DO USUÁRIO)

📄 ServiceCollectionExtensions.cs

```csharp
using FlowMapper.Abstractions;
using Microsoft.Extensions.DependencyInjection;

namespace FlowMapper.DependencyInjection;

public static class FlowMapperServiceCollectionExtensions
{
    public static IServiceCollection AddFlowMapper(
        this IServiceCollection services,
        Action<FlowMapperConfigurationBuilder>? configure = null)
    {
        var builder = new FlowMapperConfigurationBuilder();

        configure?.Invoke(builder);

        var options = builder.Build();

        services.AddSingleton(options);

        // runtime mappers (gerados pelo source generator)
        RegisterGeneratedMappers(services);

        return services;
    }

    private static void RegisterGeneratedMappers(IServiceCollection services)
    {
        var mappers = AppDomain.CurrentDomain.GetAssemblies()
            .SelectMany(a => a.GetTypes())
            .Where(t => t.IsClass && !t.IsAbstract)
            .Where(t => t.GetInterfaces().Any(i =>
                i.IsGenericType &&
                i.GetGenericTypeDefinition().Name.Contains("IMapper")));

        foreach (var mapper in mappers)
        {
            foreach (var iface in mapper.GetInterfaces())
            {
                services.AddScoped(iface, mapper);
            }
        }
    }
}
```
