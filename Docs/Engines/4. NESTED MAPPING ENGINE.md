### 🌳 FLOWMAPPER v1 — NESTED MAPPING ENGINE
----------

### 🧠 1. VISÃO DO SISTEMA

O Nested Mapping Engine permite mapear **objetos dentro de objetos**, de forma automática e previsível.

Exemplo:

```
User → UserDto
User.Address → AddressDto
User.Address.City → CityDto
```

----------

### 🎯 2. OBJETIVO

O engine deve suportar:

-   🌳 objetos aninhados (1 nível e multi-nível)
-   🔁 recursão controlada
-   🧠 detecção de tipos complexos
-   ⚡ geração em compile-time (Source Generator)
-   ❌ sem runtime reflection

----------

### 🚫 3. FORA DE ESCOPO (v1)

Não entra no MVP:

-   ciclos infinitos (A → B → A)
-   custom depth control
-   mapeamento condicional
-   flatten avançado configurável
-   projeções LINQ
-   lazy mapping

----------

### 🧱 4. NOVA REGRA DE CONVENÇÃO (EXPANSÃO DO v1)

Antes:

✔ Name + Type iguais

Agora adicionamos:

### 🌳 Regra de Nesting

Se uma propriedade for um tipo complexo, o FlowMapper deve:

> tentar encontrar outro Flow compatível para aquele tipo

----------

### 🧠 5. EXEMPLO BASE

----------

### ⚙️ 6. COMPORTAMENTO DO ENGINE

### Regra principal:

Quando encontrar:

```
Property.Type = ComplexType
```

O FlowMapper faz:

1.  procura Flow existente para aquele tipo
2.  se existir → reutiliza
3.  se não existir → cria Flow aninhado automaticamente

----------

## 🔁 7. ALGORITMO DO NESTED MAPPING

### STEP 1 — detectar tipo complexo

```
if (!IsPrimitive(type))
```

----------

### STEP 2 — procurar Flow existente

```
FlowRegistry.Find(sourceType, destType)
```

----------

### STEP 3 — se existir

```
use nested mapper
```

----------

### STEP 4 — se não existir

```
generate nested Flow recursively
```

----------

### STEP 5 — gerar chamada no código

----------

### 🧾 8. EXEMPLO DE CÓDIGO GERADO

```csharp
public UserDto Map(User source)
{
    return new UserDto
    {
        Name = source.Name,
        Address = MapAddress(source.Address)
    };
}
```

----------

### Nested mapper gerado automaticamente:

```csharp
private AddressDto MapAddress(Address source)
{
    return new AddressDto
    {
        City = source.City
    };
}
```

### 🧠 11. DETECÇÃO DE TIPO COMPLEXO

Regra v1:

```
Complex = não primitivo + não string + não collection primária
```

Inclui:

-   classes
-   records
-   structs

----------

### ⚠️ 12. PROBLEMA CRÍTICO (CICLOS)

Exemplo perigoso:

```
User → Address → User
```

----------

### v1 solução simples:

```
visited types hashset
```

Se já visitado:

-   interrompe nesting
-   marca como warning (FM0006)

----------

### 🚨 13. DIAGNÓSTICO NOVO

### FM0006 — cyclic reference detected

```
Cycle detected in mapping path: User → Address → User
```
