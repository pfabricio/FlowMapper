### 🌿 FLOWMAPPER v1 — FLATTEN MAPPING ENGINE

----------

### 🧠 1. VISÃO DO FEATURE

Flatten Mapping permite transformar propriedades aninhadas em propriedades planas.

Exemplo clássico:

```
User.Address.City → UserDto.City
```

ou

```
Order.Customer.Name → OrderDto.CustomerName
```

----------

### 🎯 2. OBJETIVO

O engine deve:

-   🌳 percorrer objetos aninhados
-   🔎 resolver caminhos de propriedades
-   🧠 gerar binding automático de path
-   ⚡ manter compile-time generation (sem runtime reflection)
-   ❌ não tentar “inventar” caminhos

----------

### 🚫 3. FORA DE ESCOPO (v1)

Não entra:

-   múltiplos caminhos possíveis com ambiguidade automática
-   heurística de inteligência (NLP-like matching)
-   flatten condicional
-   custom separators avançados (v2+)
-   mapeamento baseado em nome parcial

----------

### 🧠 4. NOVA REGRA DE CONVENÇÃO (FLATTEN)

### Regra v1 (forte e simples):

Flatten só ocorre quando o desenvolvedor declara intenção implícita via estrutura:

> Se existir um caminho válido no grafo de propriedades → pode mapear

----------

----------

### 🔍 6. ALGORITMO DE FLATTEN RESOLUTION

----------

### STEP 1 — explorar árvore de propriedades

```
User
 └── Address
      └── City
           └── Name
```

----------

### STEP 2 — DFS (depth-first search)

Encontrar todos os caminhos possíveis:

```
Address.City.Name
Address.City
```

----------

### STEP 3 — match com destino

```
CityName → Address.City.Name
```

----------

### STEP 4 — escolher caminho único

Regra v1:

-   deve existir APENAS 1 caminho válido
-   se houver ambiguidade → erro (FM0009)

----------

### ⚠️ 7. REGRA CRÍTICA (SEM MAGIA)

### ❌ NÃO permitido:

-   tentar inferir intenção sem caminho claro
-   escolher “melhor” path sozinho

### ✔ permitido:

-   usar apenas paths existentes no modelo

----------

### 🧾 8. EXEMPLO PRÁTICO

### ENTIDADE

```csharp
class User
{
    public Address Address { get; set; }
}

class Address
{
    public City City { get; set; }
}

class City
{
    public string Name { get; set; }
}
```

----------

### DTO FLAT

```csharp
class UserDto
{
    public string Name { get; set; }
}
```

----------

### RESULTADO GERADO

```csharp
return new UserDto
{
    Name = source.Address.City.Name
};
```

### 🚨 11. NOVOS DIAGNÓSTICOS

----------

### FM0009 — Ambiguous Flatten Path

```
Multiple paths found for property 'CityName'
```

----------

### FM0010 — Flatten Path Not Found

```
No valid path found for 'CityName'
```

----------

### FM0011 — Invalid Flatten Depth

```
Cycle or invalid depth detected in flatten graph
```
