# Sprint 19 — Generator Decomposition (RFC-0005)

**Baseado em:** RFC-0005, ADR-0010, `Docs/Spec/rfc-0005-generator-writers.md`

**Importância:** 🟡 Média — qualidade interna, eliminar duplicação

## Objetivo

Decompor o `FlowCodeGenerator` em writers especializados, eliminando duplicação entre `GenerateMapMethod` e `GenerateNestedMethod`.

⚠️ **Output gerado deve ser 100% idêntico ao atual.** Nenhuma mudança de comportamento.

---

## Tarefas

### 1. Criar `ICodeWriter` interface

**Arquivo:** `Pipeline/Generator/ICodeWriter.cs`

```csharp
public interface ICodeWriter
{
    void Write(CodeWriterContext context, StringBuilder sb);
}
```

### 2. Criar `CodeWriterContext`

**Arquivo:** `Pipeline/Generator/CodeWriterContext.cs`

```csharp
public class CodeWriterContext
{
    public Flow Flow { get; init; } = null!;
    public string MapperName { get; init; } = string.Empty;
    public bool IsNested { get; init; }
    public string? MethodName { get; init; }
}
```

### 3. Criar `UsingWriter`

**Arquivo:** `Pipeline/Generator/UsingWriter.cs`

Escreve `// <auto-generated />`, pragmas, usings. Executado uma vez.

### 4. Criar `NamespaceWriter`

**Arquivo:** `Pipeline/Generator/NamespaceWriter.cs`

Escreve `namespace FlowMapper.SourceGenerator[.Profiles.{ProfileName}];`. Executado uma vez.

### 5. Criar `ClassWriter`

**Arquivo:** `Pipeline/Generator/ClassWriter.cs`

Escreve `[FlowProfile]` (se aplicável) e `public partial class ... : IMapper<,>`. Abertura da classe.

### 6. Criar `ConstructorWriter`

**Arquivo:** `Pipeline/Generator/ConstructorWriter.cs`

Escreve a construção do objeto destino:
- `ConstructUsingMethod` → `var target = {method}(source);`
- Constructor binding → `var target = new TDest(p1, p2);`
- Padrão → `var target = new TDest();`

### 7. Criar `PropertyWriter`

**Arquivo:** `Pipeline/Generator/PropertyWriter.cs`

Escreve atribuições de propriedades (Direct, Flatten, MapFromExpression).
Inclui `NormalizeExpression()`.

### 8. Criar `NestedWriter`

**Arquivo:** `Pipeline/Generator/NestedWriter.cs`

Escreve:
- Chamadas a métodos nested no método principal
- Geração dos métodos nested (reusando ConstructorWriter + PropertyWriter)
- Suporte recursivo para nested de nested

### 9. Criar `AfterMapWriter`

**Arquivo:** `Pipeline/Generator/AfterMapWriter.cs`

Escreve a chamada `AfterMap` quando configurada.

### 10. Refatorar `FlowCodeGenerator`

**Arquivo:** `Pipeline/Generator/FlowCodeGenerator.cs`

Substituir lógica inline por orquestração dos writers.

**Verificar:** output idêntico via snapshot tests.

### 11. Atualizar testes

**Arquivos:**
- `tests/FlowMapper.UnitTests/` — adicionar testes por writer
- `tests/FlowMapper.SnapshotTests/` — verificar que snapshots não mudaram
- `tests/FlowMapper.Generator.Tests/` — confirmar que código gerado é idêntico

### 12. Remover arquivos antigos (se aplicável)

Nenhum — `FlowCodeGenerator.cs` mantém o nome mas tem implementação nova.
